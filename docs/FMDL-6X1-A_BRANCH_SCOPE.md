# FMDL-6X1-A Branch Scope

This branch contains only the FMDL-6X1-A architecture, contract, schema, validator, tests, workflow and candidate validation evidence.

It does not modify:

- accepted FMDL-0 through FMDL-6 releases;
- Investment OS Release 8;
- A-share or Hong Kong Current data;
- candidate-pool membership;
- simulation holdings;
- real-account holdings;
- trading rules or trade authority.

The branch may be merged only after GitHub Actions validation passes and the candidate result is independently reviewed against the acceptance criteria.
