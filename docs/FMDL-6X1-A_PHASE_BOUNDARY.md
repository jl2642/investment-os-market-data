# FMDL-6X1-A Phase Boundary

FMDL-6X1-A is complete only as an architecture and activation-contract phase. It does not construct the US research universe and does not perform live source revalidation.

The next phase, FMDL-6X1-B, must define the anticipated research universe, instrument types, venue boundary and research/channel eligibility statuses. Source access and scalability remain FMDL-6X1-C work. Full historical build remains FMDL-6X2 work.
