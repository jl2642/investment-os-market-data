# FMDL-6X4-D Authority Boundary

FMDL-6X4-D authorizes deterministic shadow computation and recovery testing only.

It does not authorize:

- Candidate Pool admission or removal;
- Investment OS simulation-book positions or transactions;
- investment recommendations;
- brokerage connectivity;
- real-account changes;
- orders.

All published records must retain `trade_authority = NONE`.
