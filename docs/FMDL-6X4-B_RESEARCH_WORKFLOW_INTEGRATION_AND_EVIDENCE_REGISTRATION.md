# FMDL-6X4-B｜Research Workflow Integration & Evidence Registration

## Objective

Convert the accepted FMDL-6X4-A adapter baseline into a recoverable workflow-integration and evidence-registration layer without executing Public Equity Investing workflows or changing Investment OS state.

## Accepted baseline

- Seven upstream source domains are registered with stable source IDs and Manifest hashes.
- Fifty-three evidence registrations bind the seven research-pool members to Canonical Security, Canonical Issuer, Research Card and upstream source artifacts.
- Seven append-only Security Evidence Ledgers preserve registered evidence by security.
- Ninety-eight Security × Workflow mappings become explicit integration states.
- Ten partial-ready mappings receive Invocation Envelopes, but all remain `NOT_EXECUTED` pending runtime source checks.
- Fourteen workflow-owned output registration contracts define how future outputs must bind to identity, sources, evidence labels, as-of dates, quality and artifact hashes.
- No completed workflow output, investment recommendation, formal candidate promotion, simulation action or brokerage action is emitted.

## Evidence boundary

Registered evidence proves what the accepted FMDL releases contain. It does not prove that a live connector is installed, callable or fresh for a future workflow run. Every Invocation Envelope therefore requires a new minimum native source check before execution.

## Completion boundary

Acceptance means the integration and evidence-registration architecture is operational and recoverable. It does not authorize Company Tearsheet, Financials Normalizer or any other Public Equity Investing workflow to run automatically, and it does not authorize Candidate Pool graduation.
