# FMDL-6X1-C Acceptance Criteria

The phase may be accepted only when all conditions below pass:

1. Accepted FMDL-6X1-B Last-success is bound exactly.
2. Current Nasdaq and other-listed official directory coverage is reachable and parseable, directly or through the official combined archive.
3. Required SEC identity, submissions and company-facts routes succeed from GitHub Actions, or are recorded as repeatable controlled official-access limitations with no third-party proxy substitution.
4. At least one zero-cost daily-price route and one corporate-action event route are reachable and explicitly labelled non-decision-grade pending reconciliation.
5. At least one FX route is reachable.
6. Historical delisting/symbol-change coverage, ADR ratio evidence and special-instrument classification limitations are explicitly registered with downstream actions.
7. Paid routes activated and paid subscription cost both equal zero.
8. Same captured input produces an equivalent decision.
9. Live Security Master, candidate, simulation, real-account and order mutations all equal zero.
10. `trade_authority = NONE`.
11. Current/Release/Last-success publication occurs only after main-branch validation.

Required exit:

`FMDL6X1C_SOURCE_COST_AND_EXECUTION_ROUTE_REVALIDATION_ACCEPTED`
