# FMDL-7-FINAL｜Cross-market and Full-system Final Operational Acceptance

## Objective

Independently reconcile the accepted A-share, Hong Kong Stock Connect, US research-adapter and FMDL-7 operating states, verify Canonical Release 9, freeze truthful capability boundaries and publish one current handoff for future independent audit and targeted iteration.

## Final interpretation of complete integration

Complete integration means each supported market has an accepted identity, data/research contract, evidence and decision route, authority boundary, operating control and recovery path inside the same Investment OS governance model.

It does not mean:

- equal data completeness across markets;
- equal Candidate, simulation or real-account permissions;
- an active US brokerage channel;
- automatic trading;
- complete current-state confirmation;
- persistent alpha.

## Accepted market posture

- **A-share:** primary full research, decision, Candidate, simulation, real-account state and attribution path. Live action remains blocked until account confirmation and fresh market data.
- **Hong Kong Stock Connect:** accepted governed cross-market research overlay. Graduation requires human re-entry review and does not automatically create exposure.
- **US equity:** accepted research adapter. Formal Candidate promotion, formal simulation, brokerage, real account and orders remain closed.

## File Library posture

The user confirmed the File Library was cleaned. Release 9 Pointer and Start Here were independently discoverable and identity-matched. The current File Library search connector did not independently index or expose the ZIP binary; therefore binary presence is not overstated. The package remains byte-validated under FMDL-7E Release 53 and the final acceptance records this connector visibility limitation explicitly.

## Final controls

- no forced common factor score;
- no global cross-market rank;
- no ticker-only identity matching;
- no neutral fill or silent source substitution;
- no automatic Candidate, simulation or real-account admission;
- no automatic rule mutation;
- human user is the only investment authority;
- Candidate, simulation and real-account states remain separate;
- `trade_authority = NONE`.

## Exit

`FMDL7_CROSS_MARKET_AND_FULL_SYSTEM_FINAL_OPERATIONAL_ACCEPTANCE_ACCEPTED`
