# CORE Static Constitution — Current

本文件是现有`investment_os_runtime/10_CORE_STATIC/00–10`的治理索引，不替代任何现有CORE模块，也不建立第二套规则权威。

## 永久治理边界

1. GitHub `main`及已合并受治理资产是机器Canonical；聊天记忆和File Library不能覆盖它。
2. `trade_authority = NONE`；禁止自动创建、提交或执行订单。
3. 用户是投资状态变化和交易执行的最终决定人。
4. 缺失、陈旧、冲突或无法复算的数据必须降级或阻断，不得伪造精度。
5. 真实账户、模拟盘、Research和Candidate保持独立状态域，跨域变化必须形成Proposal。
6. 固定资产比例、仓位上限、评分权重、晋级阈值、止盈止损和Provider选择均不是不可变CORE。
7. 可变政策必须记录版本、成熟度、证据、负责人、生效日、复核日、晋级条件和退役条件。
8. 报告和自动化可以提出建议，不得静默修改持仓、Candidate或规则。
