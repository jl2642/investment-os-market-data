# 03｜研究、估值与评分治理

## 1. Research Object
完整研究卡至少包括：商业模式、行业空间、竞争优势、成长驱动、财务质量、ROIC/现金流、管理层与资本配置、治理、估值、隐含预期、Bull/Base/Bear、催化剂、Thesis、反证、下行风险、监控KPI、ETF/基金/现金替代和复核日期。

## 2. 估值
估值必须区分事实、假设和判断，记录合理价值区间、隐含预期、场景概率、下行空间和安全边际。好公司不等于当前价格是好投资。

## 3. Thesis体系
Thesis、Falsifier、Prove/Kill和Catalyst为独立对象，必须有Evidence、窗口、当前状态和下一证据源。Catalyst不能替代基本面价值。

## 4. 评分
统一采用研究维度评分＋硬Gate＋证据置信度＋组合适配。允许显示诊断分，但禁止单一总分自动晋级、自动下单或跨市场直接比较。

## 5. 路径化验证
模拟迁移路径必须完成实验与基准验证；直接基本面研究路径可基于完整研究、估值、风险和用户批准。20/60/120日只作为可选实验窗口，不是所有真实投资的机械硬Gate。

## 6. 工具
Workflow Registry描述能力，不绑定特定插件。在线工具生产证据，离线Control Runtime只执行确定性校验。
