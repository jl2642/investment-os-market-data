# 03｜研究、估值与评分治理

## 1. Research Object
完整研究卡至少包括：商业模式、行业空间、竞争优势、成长驱动、财务质量、ROIC/现金流、管理层与资本配置、治理、估值、隐含预期、Bull/Base/Bear、催化剂、Thesis、反证、下行风险、监控KPI、ETF/基金/现金替代、机会成本比较、能力圈陈述和复核日期。

## 1A. 能力圈 Gate
单一个股进入高置信度、READY_FOR_USER_DECISION或ADD/BUY Proposal前，必须能够简洁说明：公司如何赚钱、关键且可持续的竞争优势、决定长期现金流的2—3个核心经济变量、以及什么事实会证明Thesis错误。无法完成时不得用评分精度掩盖不确定性，应降低研究置信度、缩小仓位上限或回到ETF/基金替代路径。

## 2. 估值
估值必须区分事实、假设和判断，记录合理价值区间、隐含预期、场景概率、下行空间和安全边际。好公司不等于当前价格是好投资；估值优先使用区间和关键假设，不以目标价小数精度制造确定性。成本价只用于会计和归因，不进入内在价值判断。

## 3. Thesis体系
Thesis、Falsifier、Prove/Kill和Catalyst为独立对象，必须有Evidence、窗口、当前状态和下一证据源。Catalyst不能替代基本面价值。

## 4. 评分
统一采用研究维度评分＋硬Gate＋证据置信度＋组合适配。允许显示诊断分，但禁止单一总分自动晋级、自动下单或跨市场直接比较。

## 5. 路径化验证
模拟迁移路径必须完成实验与基准验证；直接基本面研究路径可基于完整研究、估值、风险和用户批准。20/60/120日只作为入场质量、研究流程和相对表现的可选实验窗口，不是长期商业质量的机械硬Gate；长期Thesis至少在季度和年度复盘中按经营、现金流、资本配置和估值证据重新验证。

## 6. 工具
Workflow Registry描述能力，不绑定特定插件。在线工具生产证据，离线Control Runtime只执行确定性校验。
