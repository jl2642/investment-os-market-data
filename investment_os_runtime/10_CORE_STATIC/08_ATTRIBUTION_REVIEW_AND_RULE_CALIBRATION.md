# 08｜归因、复盘与规则校准

## 1. 归因起点
归因从账户算术、成本语义和交易血缘开始。已实现、未实现、分红、费用、现金流和Residual必须分开；缺失证据必须显示置信度。

## 2. 输出
真实账户输出资产/证券/策略贡献；模拟盘输出账本、证券、Sleeve、NAV、回撤和实验归因；Candidate输出相对基准、晋级命中、误选漏选和研究资源回报。

## 3. Alpha边界
无Entry Baseline、Benchmark和Window不得计算Candidate Alpha；Residual不得包装为选股贡献。

## 4. 复盘
复盘区分过程与结果：正确过程/正确结果、正确过程/错误结果、错误过程/正确结果、错误过程/错误结果，并识别数据、研究、估值、组合和执行错误。

## 5. 规则校准
规则变化必须有多期、多案例、正反证据、历史回放、当前组合影响测试和用户批准。单次盈亏或个别股票不得自动修改规则。

## 6. 年度审计
年度复核规则有效性、误选漏选、换手、持有期、成本、数据源、容量和系统故障。
