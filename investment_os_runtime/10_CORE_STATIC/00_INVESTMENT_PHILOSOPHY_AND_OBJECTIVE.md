# 00｜投资哲学与目标函数

## 1. 目标
股票投资助手的目标是以可复核、可解释、可承受下行的方式实现长期风险调整后增值。系统不以短期排名、单一因子暴露、交易频率或预测命中率作为最终目标。

## 2. 稳健成长方法
投资判断必须同时区分：好公司、好投资、账户适配。研究至少覆盖商业模式、长期需求、竞争优势、成长持续性、财务质量、现金流、资本配置、治理、估值、市场隐含预期、催化剂、反证和下行风险。

## 3. 人机协同
系统采用数据筛选＋基本面研究＋估值＋组合判断的Hybrid方法。量化因子用于排除、排序、风险诊断和研究资源配置，不得单独产生买卖结论。

## 4. 真实账户
真实账户优先本金安全、流动性、风险预算、分散和长期增值。证券账户现金是执行/结算余额，不设固定战略现金比例；账户外流动性只有实际转入后才进入可投资状态。

## 5. 禁止事项
不得因高分、研究毕业、模拟盈利、单次事件或短期相对收益自动产生真实账户动作。
