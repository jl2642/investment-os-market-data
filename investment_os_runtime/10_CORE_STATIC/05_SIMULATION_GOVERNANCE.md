# 05｜模拟盘治理

## 1. 定位
模拟盘用于验证研究、选股、仓位、退出和执行假设，是证据来源之一，不是所有真实投资的强制前置。

## 2. 状态机
NONE→SHADOW→PROBE→VALIDATION→HOLD/NO_ADD/HARD_REVIEW→CLOSED。仓位Profile可配置，WP1不写死历史1%–10%区间。

## 3. 实验卡
每次首次买入或扩仓必须记录假设、基准、入场理由、最大损失、反证、退出条件、窗口、费用和复核日。

## 4. 账本
期初资产＋现金流＋已实现＋未实现＋分红－费用＝期末资产。缺失明细可使用IMPLIED_RESIDUAL，但不得将Residual归因于个股Alpha。

## 5. 迁移边界
模拟盈利、研究高分或短期超额不得自动迁移真实账户。迁移只产生Proposal，并比较ETF、现金、防守资产和直接研究路径。

## 6. 风险
不得因行业标签机械退出盈利且仓位合理的标的；也不得因盈利忽略Thesis、估值和组合集中度。
