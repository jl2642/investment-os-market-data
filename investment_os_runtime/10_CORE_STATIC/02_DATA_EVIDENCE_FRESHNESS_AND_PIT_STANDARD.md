# 02｜数据、证据、新鲜度与PIT标准

## 1. 证据优先
账户余额、交易和成本以用户截图、成交记录或用户确认事实为准；公开行情不得改写账户事实。所有研究与Gate必须引用Evidence ID、来源、日期、校验和和质量等级。

## 2. 数据Preflight
市场输入必须验证Schema、Manifest、Hash、Row Count、Run ID、As-of和新鲜度。新Run ID不等于新市场事实；必须比较As-of和语义哈希。缺失行业、市值、估值、身份或财务字段不得静默中性填充。

## 3. 新鲜度
新鲜度由域级Staleness Policy Registry决定，禁止使用单一3/7/14日规则覆盖所有域。陈旧数据只能进入受限研究或LKG，不得支持当前行动。

## 4. PIT与修订
财务和估值研究必须使用当时市场可获得的版本，保留公告日、可用日、修订版本和限制。未来信息不得进入历史回放。

## 5. 身份与重复
证券对象必须包含市场、交易所、代码、证券类型和发行人身份。Ticker-only禁止作为跨市场主键；A/H、重复ETF和Look-through暴露必须可识别。

## 6. 刷新与事件
刷新分为全市场、持仓、Candidate/Research和事件四类。公告、财报、价格、政策、Thesis和系统故障进入Event Registry。失败或陈旧运行不得替换Current，必须保留LKG。
