# 06｜组合、仓位与资金迁移

## 1. 仓位决定因素
仓位由账户目标、下行风险、相关性、流动性、交易单位、证据置信度和组合角色决定，不由排名或总分决定。集中度必须由理解深度、证据质量和可承受下行逐步获得，不因模仿任何投资者而机械提高。

## 2. 三类权重
研究优先级、模拟权重和真实资金权重必须分离。目标可为区间、上限或无目标；证券账户执行现金不作为战略资产桶。

## 3. 组合适配
行动建议必须说明当前权重、建议区间、资金来源、最大损失、相关性、Look-through暴露、替代方案、退出条件和复核日。

## 4. 三条准入路径
配置工具路径：ETF/基金等可直接进行组合研究；直接基本面路径：完整研究、估值、风险与用户批准；模拟迁移路径：需实验和基准证据。

## 5. 资金迁移与机会成本 Gate
BUY/ADD/REDUCE/EXIT/REPLACE必须比较现金、防守资产、ETF、个股和分步执行方案。任何BUY/ADD/REPLACE Proposal至少要显式比较：不行动/保留现金、一个合适的宽基或行业ETF替代、以及当前组合中最优的已有资本用途；若没有足够证据证明新方案在风险调整后更优，则默认NO_ACTION。模拟结果或Stock Alpha不构成自动迁移许可。

## 6. 重复暴露
重复ETF、A/H、同发行人、行业和债基Look-through暴露必须进入组合风险复核。
